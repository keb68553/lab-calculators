# Rosenberg Lab Calculators

Local tools for common lab math — HiFi/Gibson assembly ratios, CRISPR electroporation mixes,
Western blot sample buffer, primer Tm/Ta + dimer checks, and restriction digests.

Pure client-side HTML/CSS/JS — no build step, no server, nothing you enter is sent anywhere.

## Use it

- **Online:** open the GitHub Pages link for this repo (see the repo's "About" section on GitHub).
- **Offline:** clone or download this repo and open `index.html` directly in a browser.
