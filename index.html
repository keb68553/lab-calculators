Dimer Check

Scans every possible antiparallel offset between the strands for the longest run of Watson-Crick complementary bases, then scores that run with the same nearest-neighbor thermodynamics as the Tm calculation above — the same approach IDT's OligoAnalyzer describes for its Self-Dimer / Hetero-Dimer check. Not affiliated with IDT and not guaranteed to match their exact numbers (their calculation runs server-side); this uses the standard published method with no reaction-salt adjustment to ΔG.
